% SlideMage manual, chapter "Decks and deck versions": the deck-level tools.
\setSlideVersion{1-2-0+}
\begin{standardframe}{Deck housekeeping}
	\small
	A collection of decks grows every term. These tools keep it manageable;
	none of them deletes anything -- what is archived can always be moved back.
	\par\medskip
	\shrinklists{1}
	\begin{itemize}
		\item \textbf{The workdeck}, \SMCode{decks/\#workdeck.tex}: your scratch deck, first in the deck switcher
		\item \textbf{Duplicate deck\ldots} copies a deck under a new name, for next term's course, and opens the copy
		\item \textbf{Archive deck\ldots} moves a finished deck to \SMCode{decks/archive/}, offering a snapshot first (next slide); the archived decks, listed at the foot of the deck switcher, still compile
		\item \textbf{Deck settings\ldots} (\SMCode{Ctrl+,}): a deck's template, dark slides where the template has them, language, footer text, output folders; the \emph{CampusOnline} plugin adds the course link and \emph{Admin slides}, a title slide and a session table
		\item \textbf{Used in decks}: a panel lists the decks that use the slide in focus, so you see what an edit affects
		\item These are in the \emph{Deck} menu; the \emph{Housekeeping} menu archives unused slides and images
	\end{itemize}
\end{standardframe}
