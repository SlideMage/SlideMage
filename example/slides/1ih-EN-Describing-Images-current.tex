\begin{standardframe}{Describing images}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.50\linewidth}
			\footnotesize
			A reader who cannot see an image needs a description of it. You write each  description once, on the \emph{Images} page (the \emph{Images} button at the top), and  SlideMage puts it into every PDF and transcript that shows the image.
			\par\smallskip
			\vspace{1em}
			\scriptsize
			\begin{itemize}
				\item \textbf{Per image.} An image is either \emph{decorative}, and screen readers skip it, or \emph{informative}, and then gets a short and a long description. Both are stored once per language.
				\item \textbf{Per slide.} A \emph{takeaway} says in one sentence why the image is on this slide.
				\item \textbf{Source.} The credit you enter for an image is printed under each slide that shows it (the \emph{Image source:} line below).
				\item \textbf{Drafts.} A local AI model can write a first version for you to correct; see the next slide.
			\end{itemize}
		\end{column}

		\end{column}
	\end{columns}
\end{standardframe}
