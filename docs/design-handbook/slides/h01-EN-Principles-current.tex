\begin{standardframe}{Design handbook: principles}
\begin{itemize}
\item Core contributors and plugin authors share one source: \SMCode{ui/kit/tokens.py}.
\item Use standard kit widgets first. Add a variant only when useful hierarchy is lost.
\item Merge colours, gaps and styles by purpose; check fit, focus and readability in both themes.
\item Kit widgets follow light/dark automatically. Refresh your own painted parts.
\end{itemize}
\end{standardframe}
