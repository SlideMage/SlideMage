\begin{standardframe}{Deck tags and groups}
	\small
	The main window sorts your decks into groups -- course decks, research
	talks, test decks, with the workdeck on top -- so a long list stays easy to
	scan. A deck's group is a tag kept in the deck file itself, so it travels
	with the deck.
