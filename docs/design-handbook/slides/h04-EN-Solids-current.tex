\begin{standardframe}{Status: solid fills}
\input{snippets/solids.tex}
\begin{itemize}
\item Core error badges and presenter warnings use a solid fill with \SMCode{on\_solid} text.
\item The solid fills stay dark in both themes for white text. Do not pair white with the brighter dark-theme \SMCode{warning}.
\item Plugins use the public tint pairs or standard widgets; solid fill fields are core only.
\item Correct-answer panels: \SMCode{ok\_bg} background and \SMCode{ok} border.
\end{itemize}
\end{standardframe}
