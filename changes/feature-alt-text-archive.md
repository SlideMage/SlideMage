kind: new
reason: direct request: an alt-text archive that keeps the descriptions of deleted and archived slides and images, phase 1 of docs/plans/alt-text-archive.md

New module alt_archive.py and the file media/archive/alt-text-archive.json (own format version 1; media/alt-text.json stays at version 3). A snapshot list per key, newest last: `images` holds whole entries (every language, role, source, drafted_by, hint and the slides they were used on), `slides` holds what belongs to one slide alone (takeaway overrides, reviewed stamps and hashes per image, the summary). archive_slides() and archive_images() write the archive first and change the store second, add a snapshot only if its content differs from the newest, drop an entry with no text without a snapshot, and refuse a newer archive (NewerStoreError). An image goes whole only when every use of it was by the archived slides and no slide file in slides/ references it. restore_image() and restore_slide() never overwrite text that is there (restore_image(overwrite=True) does, and merges the slide uses); purge_*() is the only thing that deletes a snapshot. unreferenced_entries() lists the entries no slide shows, for the review in phase 2.

Hooks: slide_rename.delete_slide_id() archives the slide's takeaways, reviewed stamps and summary instead of dropping them (before, they were lost and the image entries stayed); unused_content.archive_files() archives the data of each slide that has no current file after the move (a frozen version of a live slide changes nothing) and the entries of the moved media files; the Images page's "Replace image" offers to move the now-unused description to the archive instead of deleting it; the Delete slide dialog says so. alt_images gains the public entry_to_dict(), use_to_dict() and use_from_dict(). alt_images.delete_entry() has no caller any more. Tests: tests/test_alt_archive.py (16), test_images_page_gui.py adjusted.

NEW: Deleting or archiving a slide, or archiving or replacing an image, no longer throws its image descriptions and slide notes away: they move to an alt-text archive in media/archive/.
- Deleting a slide keeps its takeaways, review marks and summary in the archive.
- Archiving unused slides or media moves the descriptions nothing uses any more to the archive.
- "Replace image" offers to archive the old description instead of deleting it.
