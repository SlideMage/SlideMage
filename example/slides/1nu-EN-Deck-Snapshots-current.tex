% SlideMage manual, chapter "Decks and deck versions": deck snapshots (v5.33.0).
\setSlideVersion{1-0-0}
\begin{standardframe}{Deck snapshots}
	\small
	A snapshot freezes a deck: a folder (or \SMCode{.zip}) with everything it needs to compile exactly as it does today -- whatever later changes in the project, the framework or SlideMage.
	\par\medskip
	\shrinklists{1}
	\begin{itemize}
		\item \textbf{Create}: \emph{Decks} $\rightarrow$ \emph{Create deck snapshot...} -- one or more decks, folder or \SMCode{.zip}, optionally with the LaTeX package files and the SlideMage app; \textbf{Archive} offers one first
		\item \textbf{Where}: \SMCode{snapshots/<deck>\_<date>\_<time>}, as many as you like; SlideMage asks whether older ones go to the Recycle Bin
		\item \textbf{Checked}: each version is compiled, what it reads is copied, and the snapshot is rendered from its own folder and compared page by page (twice a normal compile's time)
		\item \textbf{Use}: \SMCode{render.bat} or \SMCode{render.sh}; \SMCode{reference-pdf/} holds the original PDFs. Only the TeX installation itself is not frozen
	\end{itemize}
\end{standardframe}
